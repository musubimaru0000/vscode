# AI会話アプリ

2体のAIエージェント（ペルソナ・使用するAPI・モデルをそれぞれ個別に設定可能）に、お題について会話させるフロントエンドのみの単一HTMLアプリです。

## 使い方

1. `index.html` をブラウザで直接開く（サーバー不要）
2. エージェントA・Bそれぞれについて、プロバイダ・モデル名・APIキー・ペルソナ（システムプロンプト）を入力
3. お題、最初に話すエージェント、最大ターン数などを設定
4. 「会話を開始」を押す

会話の下にある入力欄から、いつでも（自動会話の実行中でも）自分の発言を割り込ませることができます。送信した発言はその後のAIの応答に反映されます。

「両方のエージェントが1回ずつ話したら一時停止し、あなたの発言を待つ」を有効にしている場合（デフォルトで有効）、AI2体がそれぞれ1回ずつ発言するたびに会話が止まり、あなたが発言するか「スキップ」ボタンを押すまで次のラウンドは始まりません。自動でどんどん進めたい場合はこのチェックを外してください（その場合は「ターン間の待機（秒）」の間隔で自動的に進みます）。

各エージェントの「表示名」は画面上のラベルとしてだけでなく、システムプロンプトにも「あなたの名前は『○○』です」として自動的に組み込まれるので、AI自身も自分の名前を認識した状態で会話します。

会話ログはブラウザの`localStorage`に自動保存されるので、タブを閉じたり長期間放置したりしても、同じブラウザで`index.html`を開き直せば続きが復元されます（「会話を開始」を押すと、続きの発言者から自動的に再開します）。ただしAPIキーは「このブラウザに保存する」を有効にしていない限り保存されないため、再開時に入力し直しが必要な場合があります。「リセット」を押すと保存された会話も削除されます。

APIキーはブラウザ内のJavaScriptから各プロバイダのAPIへ直接送信されます。このアプリ自体にサーバー・バックエンドはなく、キーが外部（開発者側）に送られることはありません。「このブラウザに保存する」を有効にした場合のみ、`localStorage` に保存されます（共有端末では非推奨）。

## 対応プロバイダ

- Anthropic (Claude) — Messages API を `anthropic-dangerous-direct-browser-access` ヘッダー付きでブラウザから直接呼び出します
- OpenAI — Chat Completions API
- Google (Gemini) — Interactions API（`generateContent`ではなく、Googleが新規開発に推奨している新しいAPI）。会話履歴はGoogle側がサーバーで管理し、`previous_interaction_id`でスレッドを継続します

モデル名は自由入力です。各社の最新モデルIDをそのまま入力してください。Geminiについては、Google AI Studioの画面に出てくる表示名（例:「Gemini 2.5 Flash-Lite」）をそのまま貼り付けても、アプリ側で自動的にAPI用のモデルID（`gemini-2.5-flash-lite`）に変換されます。

### Geminiエージェントの注意点

- Interactions APIは会話をサーバー側で保持するため、Geminiエージェントの最大トークン数設定は現状反映されません（Anthropic・OpenAIには反映されます）。
- 「リセット」ボタンを押すと、Google側のスレッドも含めて会話が完全にリセットされます。
- Google側のスレッド（`previous_interaction_id`）がどれくらいの期間で失効するかは公式に確認できていません。長期間放置した後に再開してスレッドが失効していた場合は、保存されている会話全文を読み込ませて自動的に新しいスレッドとして再開します（画面上の会話ログが失われることはありません）。

## 注意事項

- ブラウザから直接APIキーを送信する構成のため、本番公開や他人と共有する環境での利用は推奨しません（個人利用・ローカル実行を想定）。
- プロバイダ側のCORSやレート制限、料金は各社の仕様に従います。

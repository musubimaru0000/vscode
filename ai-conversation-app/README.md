# AI会話アプリ

2体のAIエージェント（ペルソナ・使用するAPI・モデルをそれぞれ個別に設定可能）に、お題について会話させるフロントエンドのみの単一HTMLアプリです。

## 使い方

1. `index.html` をブラウザで直接開く（サーバー不要）
2. エージェントA・Bそれぞれについて、プロバイダ・モデル名・APIキー・ペルソナ（システムプロンプト）を入力
3. お題、最初に話すエージェント、最大ターン数などを設定
4. 「会話を開始」を押す

APIキーはブラウザ内のJavaScriptから各プロバイダのAPIへ直接送信されます。このアプリ自体にサーバー・バックエンドはなく、キーが外部（開発者側）に送られることはありません。「このブラウザに保存する」を有効にした場合のみ、`localStorage` に保存されます（共有端末では非推奨）。

## 対応プロバイダ

- Anthropic (Claude) — Messages API を `anthropic-dangerous-direct-browser-access` ヘッダー付きでブラウザから直接呼び出します
- OpenAI — Chat Completions API
- Google (Gemini) — generateContent API

モデル名は自由入力です。各社の最新モデルIDをそのまま入力してください。

## 注意事項

- ブラウザから直接APIキーを送信する構成のため、本番公開や他人と共有する環境での利用は推奨しません（個人利用・ローカル実行を想定）。
- プロバイダ側のCORSやレート制限、料金は各社の仕様に従います。
